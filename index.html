HOW TO PLAY
Move: Swipe anywhere on screen — release to stop. WASD on desktop.

Attack: Automatic — targets nearest enemy.

Abilities: 3 large buttons at the bottom. Keys 1 2 3 on desktop. Your class skill also floats as an icon above the left skill button.
Each class starts with a base element. Level up your Class Profile to unlock more.

Overload: Your class element matches weapon element → enhanced effects.
Combo: Two different elements equipped → combo element activates automatically.

Teammate applies a status, you hit with the matching element = CROSS-COMBO for massive damage.

🧊 Freeze + 🔥 Fire = SHATTER (3× damage)
💧 Soaked + ⚡ Lightning = CONDUCTANCE (chains all)
☠️ Poisoned + 🔥 Fire = VENOM FLARE (AOE)
🌑 Cursed + 💫 Holy = EXORCISM (4× damage)
Darkness creeps inward from the map edges. Stay inside or take damage — if it fully closes, you lose.

Clear enemy clusters to push it back.

Find 3 Purge Stones on the map. Stand on one to channel it (5 seconds, interrupted by hits).

All 3 activated → corruption reverses → Final Boss spawns. Kill it to win the level.
In-Run: Kill enemies → XP → level up → pick a card (class skill / weapon skill / item / element).

Collect XP gems dropped by enemies for bonus XP.

Weapon XP: Use a weapon to rank it up, unlocking passive skills.

Class Profile: Earns XP after runs. Each level permanently unlocks elements and perks.
Quick Join: Instantly joins or creates a public lobby.
Create Private: Generates a 4-letter code to share with friends.
Join with Code: Enter a friend's code.

The host hits START when everyone is in. The game won't begin until the world is fully loaded — no empty arenas.
